# Gu combat skill profiles — retired

Realtime skill profiles were removed from `Gu.csv`, `gu_dictionary`, the API, and the Gu wiki page. The former JSON examples and field reference are no longer a supported authoring contract.

Turn-based Gu behavior is authored through the existing `effects` data and supported simulator operations. Missing simulator behavior is tracked in `docs/architecture/REALTIME_COMBAT_TO_TURN_BASED.md`.
